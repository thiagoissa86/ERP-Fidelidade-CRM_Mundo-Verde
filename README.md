# ERP Fidelidade CRM - Mundo Verde

Sistema ERP/CRM com automação e inteligência para gestão de clientes, vendas, produtos e fidelidade.

## Stack

- Supabase (Banco de dados)
- N8N (Automações)
- Z-API (WhatsApp)
- Next.js (Frontend - futuro)

## Objetivo

Automatizar vendas, relacionamento com cliente e recomendação de produtos através de IA.
